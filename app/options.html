Steady helper options

Set these up once, on the computer the helper runs on. Everything here stays in this browser.

How much the helper does at first

The person can change this at any time from the helper panel, and the helper only ever offers more help: it never takes it.

AI fallback for unfamiliar pages (optional)

On the pages it knows, the helper follows verified steps and needs no AI. If a portal shows a page it doesn't know, it can ask Claude for the next safe step.

What is sent: a masked description of the page: button and field labels, whether each field is filled or empty, list options, and messages with all numbers removed. Never sent: Aadhaar, OTPs, captcha, names, phone numbers, addresses, or anything typed. Whatever the AI suggests is checked against the same rules: it can never fill private fields, tick consent or press Submit.

Stored only in this browser profile's extension storage. Anyone with access to this browser profile could read it, so use a key with a spending limit.

Saved answers

The helper keeps answers on this computer (encrypted) so a portal timeout doesn't mean starting again. Aadhaar is kept only if the person agreed. Everything is deleted after the application is sent, or after 7 days.
