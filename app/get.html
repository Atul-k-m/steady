Install the helper

About five minutes, once, on the laptop your parent will use. You need Google Chrome. The helper isn’t in the Chrome Web Store yet, so Chrome loads it from a folder.

  1. Download the helper

    It’s a zip file of about half a megabyte. Chrome saves it in your Downloads folder.

    Download steady-extension.zip

    Running Steady from its code folder (local development)? There’s no zip there. Skip to step 3 and choose the app folder itself.

  2. Unzip it

    Open Downloads, right-click steady-extension.zip, choose Extract All… and then Extract. You get a folder called steady-extension with a file named manifest.json inside.

    Move that folder somewhere it won’t be tidied away, such as Documents. Chrome reads it from there every time it starts.

  3. Open Chrome’s extensions page

    Type this into Chrome’s address bar and press Enter. Web pages aren’t allowed to link to it, so it has to be typed or pasted.

    chrome://extensions

  4. Turn on Developer mode

    It’s a switch at the top right of the extensions page. It lets Chrome load an extension from a folder. It doesn’t change anything else.

  5. Click “Load unpacked”

    The button appears at the top left. Choose the steady-extension folder (or the app folder in local development) and click Select Folder. Steady now appears in the list.

    To keep it in reach, click the puzzle-piece icon next to the address bar and pin Steady.

  6. Come back and reload this page

    The box on this page should then say Helper found ✓. When Chrome starts, it may warn about extensions in developer mode. That’s because this one isn’t from the Web Store yet. Close the warning, but don’t choose to turn the extension off.

The AI key goes in the extension, never on this website

The helper follows a checked map of the practice portal’s steps and needs no AI for that. If it reaches a page it doesn’t recognise, it can ask an AI model what to do next, but only if you add an API key.

To add one, right-click the Steady icon, choose Options, and paste the key there. It stays in the extension’s storage on this computer. This website never asks for it, and couldn’t send it anywhere: its security policy blocks every network connection.

What the AI receives is a masked description of the form: the labels, which fields are filled, and error messages with numbers removed. It never receives the Aadhaar number, an OTP, a name, a phone number or any answer typed in. More on your data
